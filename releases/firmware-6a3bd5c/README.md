# Firmware 6a3bd5c build package

Target: Waveshare ESP32-S3-Touch-LCD-1.46 standard glass, SKU29565. Built from clean source `6a3bd5c49f42d900c69e7243303628de3f35d563` with official ESP-IDF 5.3.6 (`79e3454c68248bd7d881721c9b2e94561378a8ce`). Compiler warnings: 0. These raw images are build records, not an automatic installer.

This image is schema 23 / rules 16. Snapshots are 3,216 bytes and native `State` is 3,188 bytes on the host that produced the ABI check. The level cap is 50. A wild encounter is the partner's level, one below, or one above, then clamped to 1–50. That one-level band is the change in this image. Selected XP companions earn the victory or capture bond once. A new duplicate merges into the oldest owned exact form. Failed captures stay in the same battle for three attempts. Auto battles start on their own, Run Away remains, and capture stays a manual throw. Critical hits are 5% at 1.5× damage. Useful care grants 2 XP off cooldown. Powered-off and overnight time are not punished. Walking step gaps are unchanged. The motion detector is unchanged: false steps while stationary remain unresolved.

[manifest.json](manifest.json) gives the four image hashes, sizes and build layout offsets. The partition table and OTA-data images match the bytes already recorded for the installed `171cda7` layout. The bootloader image does **not** match that installed bootloader. Their presence is a reproducibility record, not an instruction to overwrite those regions. For a compatible existing installation, the reviewed update scope is application-only at `0x20000`, after preserving that unit's own NVS, settings and SD card. Never erase an existing save to accommodate an update.

The application is 1,608,048 bytes, 176 bytes larger than `53686e6` and 6,992 bytes larger than `171cda7`, with 1,537,680 bytes free in its 3 MiB OTA slot. Static DIRAM is 213,055 of 341,760 bytes, the same DIRAM use as `53686e6`. Linker remainder is not runtime heap. The application stack chain and the synthetic JSON maximum were not remeasured; do not reuse the `171cda7` figures for this binary. [Resource summary](resource-summary.json).

The historical [53686e6 package](../firmware-53686e6/README.md) and [171cda7 package](../firmware-171cda7/README.md) stay the records of those earlier installations. This package does not include saves, credentials, private art or device identifiers.

Both connected boards received this application at `0x20000` only. Bootloader, partition table and OTA metadata were not written, and the chip was not erased. The active partner and selected XP companions were not released, and the release path granted no merge XP. Each release checkpoint committed the rules 16 snapshot. A later read-only reboot on each board left that save unchanged. The board that was already in an encounter was returned to Auto in NVS and was not booted again. The SD cards were not mounted or written. [Sanitized installation result](installation-summary.json). False steps while stationary remain unresolved, and this package does not include a photograph of either screen.
