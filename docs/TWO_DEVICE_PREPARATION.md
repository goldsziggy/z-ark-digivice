The private staged pack contains **261 files / 4,700,573 bytes**: 251 DVA files, eight JPGs, INDEX and ATTRIB. It covers **251 of 276 forms**; the other **25 use fallback artwork**. The [USB installer](USB_SD_TRANSFER.md) writes each board's mounted card through its existing USB cable; a Mac card reader is optional. It validates the full manifest, verifies USB/chip identity, stops on conflicting destinations, and hashes every completed file. Each unit keeps its own card, cache, identity, NVS and save. No card formatting or save cloning is performed.

Unit 1's read-only pre-upgrade boot-sector probe identified **MBR exFAT at LBA 2048**, on a **62,883,102,720-byte** card. The earlier mount failure came from disabled exFAT support. The new build enables the existing pinned FatFs exFAT implementation locally; 32-bit sector addressing remains sufficient for this card, GPT remains unsupported, and TRIM is disabled. Subsequent mounting and bounded inventory passed. Destination inspection found all 261 pack targets absent with no conflicts. All 261 files then transferred successfully: 4,700,573 acknowledged payload bytes in 733.237 seconds (6,410.714 B/s), with zero retries and the installation lease released. All 261 hashes were rechecked on `8a420c7`. Installation evidence (historical local evidence omitted).

The first physical transfer preflights exposed two integration issues before any pack files were written: initial USB startup chatter was mistaken for a later reboot, and immediate pause checks raced the audio worker's acknowledgement. The host now performs a bounded read-only startup drain before identification; later resets remain fatal. Firmware waits at most 250 ms for real peripheral barriers before touching SD. Both fixes have focused tests, and Unit 1's subsequent inspection passed. Failed-attempt logs are retained privately. A later reopen exposed an unbounded NACK wait in the pinned SDK before SD mount. The project-local official backport passed 75 sanitizer checks; after its app-only upgrade, boot, card access and software reboot passed. Host fault tests establish the bounded wait; this run does not prove recovery from every electrically stuck bus.
