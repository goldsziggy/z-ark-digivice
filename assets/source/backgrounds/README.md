## Provenance and verification

All eleven backgrounds were generated for this Digivice project with the built-in image_gen tool. The project owner approved publishing these originals. [index.json](index.json) records every master’s dimensions, byte count, SHA-256, original archive entry, and the hashes of the source archives and generation records.

The eight-environment source archive matches the SHA-256 in the [playable demo’s attribution](../../../docs/play/art/attribution.json). Its masters and supplied 480px/RGB565 variants match the preserved source provenance; the RGB565 pixels also verify exactly. The 480px browser and 412px demo JPEG hashes match their recorded attribution. The PNG masters here remain unchanged; runtime derivatives are separate.

This folder is a later, owner-approved addition of original generated backgrounds. Older frozen export records retain their own release boundaries. This addition changes no game code, runtime art, firmware, sprite source sheets, or asset catalog.
