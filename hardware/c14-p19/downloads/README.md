# C14-P19 print downloads

Each ZIP below contains the actual native 3MF project, its matching G-code,
a README and checksums. All plates are for **two devices**, prepared for
**Anycubic Kobra S1 / PLA / 0.4 mm**. Sizes below are measured archive sizes;
print time and material are slicer estimates. Each link names a ZIP included in this repository.

For an existing C13 assembly, replace only the main white front with the
matching C14-P19 front-pair repair choice. Reuse black/red parts and the small
white RF windows. For a complete new print, choose common black and common red
together with one matching full-white plate. Choose one front variant and one white option;
the repair and full-white plates are alternatives.

The full-white plates include two RF windows; repair plates contain only two
main fronts and require existing/separate windows. The windows and top housing
remain part of the enclosure even without NFC electronics. The common black
plate includes two optional reader trays, which the first touch-only build omits.

C14-P19 changes only white receiving pilots from 1.6 to 1.9 mm. Black pilots
remain 1.6 mm and through-clearances 2.4 mm. Both C13 white fronts and all old
white plates are superseded. Common black/red projects retain their original
C13 internal names and unchanged payload hashes.

See the [assembly guide](../docs/z-ark_Digivice_C14_P19_Assembly_and_Screws.pdf),
[assembly notes](../ASSEMBLY.md) and [package/member hashes](../release-assets.json).
Physical fit and screw grip remain untested. These are printer-specific
prototype toolpaths; confirm the printer/material profile before use.
